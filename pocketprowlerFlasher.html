Install Firmware

PocketProwler v2.2.0

Release date: 2026-08-28

Current PocketProwler WiFi and BLE scanner firmware for the LilyGO T-Display C5. This writes the complete factory image at offset 0x0.

Before Flashing

  1. Use Chrome or Edge on a desktop computer.
  2. Plug the LilyGO T-Display C5 in with a data-capable USB-C cable.
  3. If the installer cannot connect, hold BOOT while tapping RESET, then try again.
  4. Keep the browser tab open until the installer reports completion.

Factory Image

This browser flasher installs firmware.factory.bin for PocketProwler v2.2.0 at 0x0. It is intended for the LilyGO T-Display C5 ESP32-C5 scanner build.
